# 规则：纯前端边界（无后端 / 无服务端依赖）

> owner：架构层不变量。来源：PRD §1「数据不出浏览器」、§2 技术栈「后端：无」、§5 隐私。

## 规则

1. 所有计算在浏览器完成，**不引入后端、API 调用、服务器渲染**。
2. 唯一允许的外部请求：部署产物托管（Cloudflare Pages 静态资源）。任何运行时向自有或第三方服务器的数据上传 = 违规。
3. 运行时数据只允许存 `localStorage`（历史记录、主题选择）。不引入 IndexedDB、内存之外的存储；除非走 PRD 变更协议。
4. 构建产物必须可在纯静态托管运行：无 SSR、无 server 依赖、SPA 回退靠 `public/_redirects`（`/* /index.html 200`），不靠服务端 rewrite 配置。
5. 时间戳、时区类功能只允许用浏览器原生能力（本地时区 + UTC）；**禁止引入时区数据库（如 `Intl` 之外的 tz 库）**。

## 判例标准

- code review / 实现自审：出现 `fetch` 到自有 API、`XMLHttpRequest` 上报、`postMessage` 到远端、PWA service worker 上报 = 阻断。
- 第三方库引入前检查：是否有运行时网络行为（遥测、字体服务拉取）。允许 CDN 字体吗？**不允许**，全部资源随构建产物本地化。
