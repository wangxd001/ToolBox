# 规则：本地数据（localStorage）契约

> owner：数据契约层不变量。来源：PRD §3.2（复制/重置/示例/错误区）、§3.3 历史记录、§3.4 URL 参数、§5 隐私。

## 规则

### 键名与结构（首次写入代码时定稿后即为契约，改动需走 PRD 变更协议）

1. 每个工具的历史记录、用户偏好使用**独立、带前缀的** `localStorage` key（如 `toolbox.history.json`、`toolbox.pref.theme`），禁止裸 key（`"theme"`、`"history"`）或跨工具共享 key。
2. 历史记录结构固定为数组，写入前必须校验条数与单条上限（PRD §3.3 表格）；超限时**丢弃最旧条目**而非报错，JSON 单条 >100KB 时**不写入并提示「超出历史上限」**。
3. 读取 `localStorage` 必须容错：key 不存在 → 返回默认值；JSON.parse 失败 → 视为空并继续（不得让页面崩溃），必要时静默清理坏数据。

### URL 参数

4. 仅 PRD §3.4 允许的工具读写 URL 参数；UUID/JSON 页面**禁止**从 URL 读取输入。
5. 写入前判长度（≤2000 字符）；读取后**必须校验**，非法值回退默认值并给非阻塞提示（toast/inline），不得静默吞掉也不得 throw。

### 通用交互

6. 每个工具页必须有「清空历史」入口，点击后清空对应 key 并给出反馈。
7. 「复制」使用 `navigator.clipboard`，需处理 `document.execCommand` 降级；「重置」恢复默认示例值。

## 判例标准

- 任何 key 不带 `toolbox.` 前缀 = 违规。
- 历史写入路径缺少上限检查 = 阻断（localStorage 配额 5MB，单工具超限会挤掉主题等偏好）。
- URL 读取无 try/catch 或无回退默认值 = 违规。
