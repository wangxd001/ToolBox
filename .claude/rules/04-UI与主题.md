# 规则：UI 与主题（Tailwind dark: / 响应式 / SEO）

> owner：UI 层不变量。来源：PRD §3.1 主题、§3.2 工具页骨架、§5 响应式与 SEO。

## 规则

### 主题

1. 暗色模式**只用 Tailwind `dark:` 类**（`darkMode: 'class'`，挂在 `document.documentElement`），禁止组件内联 `style` 判断 `isDark` 做颜色切换。
2. 首次访问跟随系统 `prefers-color-scheme`；用户手动切换后写 `localStorage`（key 见数据契约规则），后续以本地选择为准。
3. 必须处理 FOUC：在路由模块之外、主 bundle 执行前的内联脚本里读 localStorage/系统偏好并设置 class，避免刷新闪白。
4. 验收（PRD §3.1）：刷新后主题保持；清除 localStorage 后恢复跟随系统。

### 工具页骨架

5. 五个工具页统一使用 `ToolLayout` 承载，子组件固定为：标题+一句话说明、输入区、操作按钮区、输出区、错误提示区、示例填充、重置、复制。新增工具不得发明新骨架。

### 响应式

6. 移动端优先：窄屏下工具页纵向排列，可点区域 ≥44px（按钮/输入框 height 或 padding 保证）。
7. 断点只用 Tailwind 默认（sm/md/lg），不新增自定义断点。

### SEO

8. 每个路由在挂载时设置 `document.title` 和 meta description（`useEffect` 或轻量 hook 统一处理）；**不做 SSR**（PRD §6）。
9. 首页卡片网格在窄屏降为单列。

## 判例标准

- 组件里 `className={isDark ? '...' : '...'}` 手动切色 = 违规，改 `dark:` 变体。
- 可点元素 <44px 触控区（不含视觉装饰）= 不通过响应式验收。
- 路由无 `document.title` 设置 = 阻断。
