# 📋 PRD：个人 Web 工具箱（Toolbox）

## 1. 产品概述

**产品名**：Toolbox（可后续自定义）
**一句话描述**：一个纯前端的 Web 工具集合，集成开发者日常高频使用的格式转换与生成工具，支持亮/暗主题切换、工具级 URL 分享和本地历史记录。
**目标用户**：开发者本人，以及有同类日常需求的开发者/测试工程师。
**核心价值**：打开即用、无需登录、数据不出浏览器。

## 2. 技术栈与架构

| 维度     | 决策                                   |
| -------- | -------------------------------------- |
| 构建工具 | Vite                                   |
| 框架     | React 18+ + TypeScript                 |
| 路由     | `react-router-dom`，BrowserRouter      |
| 样式     | Tailwind CSS + 少量自建基础组件        |
| 测试     | Vitest，只测纯函数（转换/校验/编解码） |
| 部署     | Cloudflare Pages，GitHub 集成自动部署  |
| 后端     | **无**，所有计算在浏览器完成           |

**页面结构**：
- `/`：首页，工具卡片网格
- `/tools/timestamp`：时间戳转换
- `/tools/uuid`：UUID 生成
- `/tools/json`：JSON 工具
- `/tools/base64`：Base64 编解码
- `/tools/url`：URL 编解码

**SPA 回退**：构建输出目录包含 `_redirects`，内容为 `/* /index.html 200`，确保直接访问子路径和刷新不 404。

## 3. 全局功能需求

### 3.1 主题切换（亮色 / 暗色）

- 首次访问：跟随系统 `prefers-color-scheme`。
- 提供手动切换按钮（亮色/暗色），切换后写入 `localStorage`，后续访问以本地选择为准。
- 切换按钮在全局布局可见（如顶部导航栏）。
- 使用 Tailwind `dark:` 类实现，暗色模式对 5 个工具页和首页全部生效。
- **验收标准**：刷新后主题保持；清除 localStorage 后恢复跟随系统。

### 3.2 工具页通用交互骨架

每个工具页统一包含：
- 工具标题和一句话说明
- 输入区（按工具而定）
- 操作按钮区（转换/生成/格式化等）
- 输出区
- 错误提示区（输入非法时显示具体原因）
- “示例填充”按钮
- “重置”按钮
- “复制”按钮，复制成功后显示短暂反馈

### 3.3 历史记录（localStorage）

| 工具       | 历史条数      | 单条上限        | 说明                           |
| ---------- | ------------- | --------------- | ------------------------------ |
| 时间戳转换 | 最近 10 条    | 正常输入长度    | 记录最近转换的输入/输出        |
| UUID       | 最近 10 条    | 批量结果整体    | 记录最近生成批次               |
| JSON       | **最近 5 条** | **单条 ≤100KB** | 超限不写入，提示“超出历史上限” |
| Base64     | 最近 10 条    | 正常输入长度    |                                |
| URL 编解码 | 最近 10 条    | 正常输入长度    |                                |

所有工具页提供 **“清空历史”** 入口。历史记录只存 `localStorage`，不上传任何服务器。

### 3.4 URL 参数（按工具差异化）

| 工具       | 是否支持 URL 参数 | 参数                             | 长度限制                                |
| ---------- | ----------------- | -------------------------------- | --------------------------------------- |
| 时间戳转换 | ✅                 | `ts`、`unit`（`s`/`ms`）、`mode` | 无特殊限制                              |
| UUID       | ❌                 | —                                | —                                       |
| JSON       | ❌                 | —                                | —                                       |
| Base64     | ✅（短输入）       | 编码后的输入/输出状态            | 输入 ≤2000 字符；超限只存历史，不写 URL |
| URL 编解码 | ✅（短输入）       | 同上                             | 输入 ≤2000 字符；超限只存历史，不写 URL |

读取 URL 参数时必须做校验，非法参数回退默认值并给出非阻塞提示。

## 4. 工具功能规格

### 4.1 时间戳转换

- 实时显示当前时间戳，秒/毫秒可切换。
- **时间戳 → 时间**：输出本地时间、UTC 时间、ISO 8601。
- **时间 → 时间戳**：支持日期时间输入，输出秒级和毫秒级时间戳。
- 时区范围：MVP 只支持**本地时区**和 **UTC**，不引入时区库。
- 非法输入（空、非数字、日期无效）显示明确错误。
- URL 参数：`ts`（时间戳值）、`unit`（`s`/`ms`）、`mode`（`toTime`/`toTs`）。

### 4.2 UUID 生成

- 生成 UUID **v4**。
- 批量数量：1～100。
- 选项：大写、去横线、加花括号。
- 优先 `crypto.randomUUID()`；不可用时降级为 `crypto.getRandomValues()` 手工构造 v4。
- 支持复制单条和复制全部。
- 不做 URL 参数；历史记录最近 10 次生成结果。

### 4.3 JSON 工具

- **格式化**：2 空格 / 4 空格缩进。
- **压缩**：移除所有非必要空白。
- **校验**：合法/非法；非法时显示**行号、列号和错误信息**。
- 可选 **“按键名排序”**（递归排序对象键）。
- 不做 URL 参数；历史最近 **5 条**，单条 **≤100KB**。

### 4.4 Base64 编解码

- 编码/解码双向，**必须正确支持 UTF-8 中文**（使用 `TextEncoder`/`TextDecoder` 处理 Unicode）。
- 可选 **URL-safe 模式**（`-`/`_` 替代 `+`/`/`，必要时去 padding）。
- 解码失败显示明确错误。
- URL 参数仅当输入 ≤2000 字符。

### 4.5 URL 编解码

- 默认 `encodeURIComponent` / `decodeURIComponent`。
- 可选 `encodeURI` / `decodeURI`。
- 解码失败显示明确错误。
- URL 参数仅当输入 ≤2000 字符。

## 5. 非功能需求

| 维度   | 要求                                                         |
| ------ | ------------------------------------------------------------ |
| 响应式 | 移动端优先；窄屏下工具页纵向排列，按钮可点区域 ≥44px         |
| 主题   | 亮/暗切换 + 跟随系统 + localStorage 持久化                   |
| SEO    | 每个路由设置 `document.title` 和 meta description；不做 SSR  |
| 测试   | Vitest 覆盖 5 个工具的纯函数：时间戳互转、Base64 UTF-8、URL 编解码、UUID 格式、JSON 校验/排序 |
| 隐私   | 所有输入/输出仅存于浏览器 `localStorage`，不上传任何服务器   |
| 构建   | Node 20+，`npm run build` 输出 `dist`                        |

## 6. 明确不做（MVP 边界）

- 不做后端、登录、云同步。
- 不做 MD5 哈希、Cron 解析（v1.1 候选）。
- 不做 PWA、E2E 测试、SSR。
- UUID 不做 v7。
- 时间戳不做自定义时区库，只支持本地时区和 UTC。

## 7. 部署与 CI/CD

- GitHub 仓库 push → Cloudflare Pages 自动构建部署。
- 自定义域名：从首次部署就绑定，支持 apex 和子域名，详见部署手册。
